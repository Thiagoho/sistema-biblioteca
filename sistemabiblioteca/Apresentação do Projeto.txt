Como 0 sistema funciona 
Ao iniciar a aplicação, o usuário visualiza um menu no terminal com as opções disponíveis.
O sistema mantém os dados em memória enquanto o programa estiver em execução.

CADASTRO DE LIVROS	
O usuário informa:
- TÍTULO
- AUTOR
- ANO DO PUBLICAÇÃO
- QUANTIDADE DISPONÍVELO sistema valida se os dados são válidos antes de cadastrar o livro.
CADASTRO DE USUÁRIOSO usuário informa:
- NOME
- E-MAIL
- TELEFONEO sistema valida se os campos obrigatórios foram preenchidos corretamentes.
EMPRÉSTIMO DE LIVROS
Para realizar um empréstimo, o sistema solicita o ID do usuário e o ID do livro.
Antes de confirmar o empréstimo, o sistema verifica:
- Se o usuário existe
- Se o livro existe
- Se o livro possui quantidade disponível- Se o usuário já possui empréstimo ativo do mesmo livro
Se todos as regras forem atendidas, livro é emprestado e a quantidade disponível é reduzida.
DEVOLUÇÃO DE LIVROS
Para realizar uma devolução, o sistema solicita o ID do usuário e o ID do livro.
O sistema verifica se existem um empréstimo ativo para aquele usuário e aquele livro.
Se existir, a devolução é registrada e a quantidade disponível do livro é aumentada.
DATAS
O sistemas utiliza LocalDate para registrar:
- Data do empréstimo
- Data prevista para devolução
- Data real da devolução
Por padrão, a data prevista para devolução é calculada com 7 dias ápos a data do empréstimo.
REGRAS DO NEGÓCIOS
- O título do livro não pode ser vazio.
- O autor do livro não pode ser vazio.
- O ano de publicação deve ser válido.
- A quantidade disponível não pode ser negativa.
- O nome do usuário não pode ser vazio.
- O e-mail do usuário não pode ser vazio
- O telefone do usuário nãoi pode ser vazio.
- Não é permitido emprestar livro sem estoque.
- Não é permitido empréstimo duplicado ativo do mesmo livro para o mesmo usuário.
- Não é permitido devolver livros sem empréstimo ativo.
TRATAMENTO DE EXCEÇÕES 
O projeto possui exceções personalizadas para deixar os erros mais claros e organizados.
Exceções utilizadas:
- LivroInvalidoException
- UsuarioInvalidoException
- EmprestimoInvalidoException
- LivroIindisponivelException
Essas exceções ajudam a exibir mensagens amigáveis no terminal e evitam que o sistema seja encerrado 
inesperadamente.
